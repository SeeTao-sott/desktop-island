# 灵动岛（Desktop Island）

Windows 11 上的三样东西，在同一个程序里：

- **灵动岛**：屏幕顶部正中的小胶囊。平时显示时间，鼠标移上去用弹簧动画展开。
- **侧边架子**：藏在屏幕右侧的面板，用来代替桌面：快捷方式和文件分类放在这里。
- **桌面小组件**：像手机桌面的小组件，摆在壁纸上，颜色跟着壁纸变。

## 灵动岛能做什么

| 功能 | 平时（收起） | 鼠标移上去（展开） |
|---|---|---|
| 时间 | 显示 时:分 | 大号时间 + 日期 |
| 音乐 | 小封面 + 时间 + 音量条（暂停时变暗） | 封面、歌名、歌手、进度条、上一首 / 播放暂停 / 下一首 |
| 番茄钟 | 番茄 + 倒计时；结束时绿光闪 3 下，显示"专注完成" | 底部条：开始 / 暂停 / 继续 / 结束 / 再来一轮 |
| 低电量 | 先显示"电量 X%"5 秒，之后整个胶囊带琥珀色 | 底部多一条"请插上电源" |
| 显卡高温 | 先显示"显卡 X°C"5 秒，之后整个胶囊带红色 | 底部多一条"温度偏高" |

- 音乐支持所有接入 Windows 媒体控制的播放器：Chrome / Edge 里的 YouTube、Spotify、网易云等。
- 胶囊以外的透明区域不挡鼠标，可以正常点下面的东西。
- **长按灵动岛 2 秒 = 让开**：缩成一粒小点、鼠标可以直接点到它下面的东西，3 秒后自己变回来。
- **双击灵动岛 = 回到桌面**，再双击一次把窗口恢复（双击按钮不算）。托盘 →「双击灵动岛」可以改成「全部最小化（再双击恢复）」或「不做什么」。
  回到桌面后灵动岛、架子、桌面小组件都照常显示。也可以在配置里设一个快捷键（`show_desktop_hotkey`），不能用 Win+D。

## 侧边架子怎么用

**打开**

- 鼠标推到屏幕**右边缘的中段**停一下（默认 0.3 秒）就会滑出；鼠标离开 0.5 秒后收回。
- 拖着文件推到右边缘，也会滑出来，方便直接放进去。
- 快捷键 `Ctrl+Alt+D` 打开 / 关闭，打开后可以直接打字搜索。`Esc` 或点别处也会收回。
- 用快捷键或托盘叫出来后，鼠标一直没移进去：3 秒后自己收回（正在打字搜索时不算）。点过架子后鼠标离开：1.2 秒后收回。
- 只是经过边缘、拖浏览器滚动条、点窗口右上角关闭按钮，都不会弹出来。

**放进去、拿出来**

- 把文件拖到架子上：松在标题区 = 按类型自动分类；松在某个分类上 = 放进那个分类。
- 在架子里按住一项拖出去：可以拖进网页上传框、Word、微信等。**拖出去是复制**，架子里的原件不动。
- 拖回架子松在别的分类上 = 换分类。
- 双击打开；右键菜单：打开、在资源管理器中显示、重命名、移到其他分类、从架子移除。
- 键盘：回车打开、`F2` 改名、`Delete` 从架子移除。

**分类**

- 默认：软件（快捷方式）、文档（PDF / Word / PPT / Excel / 文本）、图片、压缩包、其他（含文件夹）。
- 标题旁的 **＋** 新建分类；右键分类标题可以改名；空的自定义分类可以"移除"。
- 默认的 5 个分类不能改名或移除（自动分类要用到）。

**搜索**：顶部输入就筛选，空格分开的几个词要都包含。`↑` `↓` 选择，回车打开，`Esc` 先清空再收回。

## 文件安全

- 架子就是一个真实的文件夹：`C:\Users\User\OneDrive\架子`，每个分类是一个子文件夹。放进架子 = 把文件移进去，和放到桌面一样，也照样由 OneDrive 备份。
- **只移动，从不删除**。"从架子移除"只是移进「已移除」文件夹（架子底部的"已移除 N"可以打开它），删不删由你决定。
- 同一个硬盘直接移动；跨硬盘时按 **复制 → 逐字节核对完全一致 → 再移除原件** 的顺序，任何一步出错原件都不动。
- 重名时自动改名成"名字 (2)"，**不会覆盖**已有文件。
- 每次移动后有 **10 秒"撤销"**。
- 所有移动都记在 `%APPDATA%\com.stanley.desktopisland\shelf-log.jsonl`。
- 文件被占用或没有权限时会说清楚原因（比如"正在被 Microsoft Word 使用"），不会卡住。
- 磁盘根目录、系统文件夹、个人文件夹本身（桌面、文档、下载……）、架子自己都不允许放进来。

## 从桌面搬家 / 搬回桌面

- 托盘 →「**从桌面搬进架子…**」：列出桌面（含公共桌面）上的所有东西和各自会进的分类，取消勾选的不搬，点按钮才真正搬。被占用、没权限的会标红并自动不勾。
- 搬完会生成一份**搬家记录**（`%APPDATA%\com.stanley.desktopisland\搬家记录-日期.txt`），写着每一项原来在哪、现在在哪。
- 托盘 →「**把桌面来的东西搬回桌面…**」：把所有从桌面来的东西（包括你平时手动拖进来的）一键搬回原位置。之后在架子里换过分类、改过名也找得到。原位置已有同名文件时自动改名，不覆盖。
- 托盘 →「**隐藏桌面图标**」：和桌面右键 → 查看 →"显示桌面图标"是同一个开关，再点一次恢复。

## 桌面小组件

**在哪一层**：壁纸上面、所有程序窗口下面。点桌面、按 Win+D、切换窗口都不会跑到程序前面；点组件不会抢走你正在用的程序的焦点；不出现在任务栏和 Alt+Tab 里。组件以外的地方点击直接穿透到桌面。

**有哪些组件**（每个都有 小 2×2 / 中 4×2 / 大 4×4 三种尺寸；音频可视化另有「通栏」）

| 组件 | 内容 |
|---|---|
| 时钟和日期 | 时间、日期、星期；大尺寸带月历。设置里可以开"显示秒"和"12 小时制" |
| 音乐 | 封面、歌名、歌手、进度、上一首 / 播放暂停 / 下一首。和灵动岛是同一份数据 |
| 番茄钟 | 圆环倒计时和按钮。和灵动岛是同一个计时器，哪边操作两边一起变 |
| 系统状态 | CPU 占用、显卡温度、电量；大尺寸多一条 CPU 曲线。几秒更新一次 |
| 音频可视化 | 跟着系统正在播放的声音动（任何播放器都行，不是麦克风）。画成频谱柱（低音在左、高音在右，低音用更长的分析窗口，分得更准；会自动调整高度占满组件）。除了小 / 中 / 大，还有「通栏」：从屏幕最左边铺到最右边，适合放在最底下。设置里可选：颜色（跟壁纸 / 跟歌曲封面 / 手动 8 种颜色）、降到 30 帧。圆环主题下绕成一圈。没声音 2.5 秒后淡出、完全停止绘制 |

**编辑模式**：按 `Ctrl+Alt+W`，或托盘 →「编辑桌面小组件」。

- 屏幕变暗、出现网格点，组件浮到所有窗口上面方便摆放。
- 按住组件拖动，松手吸附到网格；虚线框是松手后的位置。被占了会自动找最近的空位。
- 鼠标移到组件上，下面出现 **小 / 中 / 大**（和齿轮设置）；左上角的 **−** 是移除。
- 顶部「**＋ 添加组件**」打开组件库，同一种组件可以放好几个。
- 点「**完成**」（或再按一次快捷键）退出，布局自动保存，重启电脑后位置不变。

**主题（所有组件一起换）**

| 主题 | 样子 | 编辑时吸附 |
|---|---|---|
| 方形 | 圆角半透明玻璃卡片 | 方形网格 |
| 圆环 | 圆形 / 胶囊形。时钟外圈发光刻度；番茄钟像技能冷却的扇形倒数；系统状态是三圈同心圆环；音乐是圆形封面 + 外圈进度 | 方形网格 |
| 科幻 HUD | 切角面板、细发光描边、四角括号角标，每 20~40 秒一道很淡的扫光；分段进度条 | 方形网格 |
| 六边形 | 平顶六边形（中尺寸是拉长的六边形），进度沿着边走 | 蜂巢网格 |

- 切换：编辑模式顶部的「主题」里点一下；或托盘 →「**切换小组件主题**」（换到下一个）。切换时组件缩小淡出、换好外观再弹回来。
- 两种网格各记一份位置：从六边形切回方形，原来的摆法还在。第一次切到六边形会自动往左上角拼好。
- 只有形状本身能点到：圆形、六边形、切角外面的透明部分点击直接穿透到桌面。
- 托盘 →「**小组件主题预览**」可以把四种主题并排看（番茄钟是模拟计时）。

**颜色跟着壁纸**

- 用 Wallpaper Engine 时：向它问当前壁纸，读壁纸文件夹里的预览图取色；没开 Wallpaper Engine 时读 Windows 壁纸。
- 每 5 秒做一次很轻的检查（看壁纸文件有没有变），变了马上取色；Wallpaper Engine 开着时每 30 秒再确认一次（播放列表自动换图也能发现）。
- 底色是带壁纸色调的半透明玻璃。文字颜色按"组件背后是纯白或纯黑"两种最坏情况来保证对比度，所以任何壁纸上都看得清。
- 换壁纸后颜色在约 1 秒内平滑过渡。
- 想固定一个颜色：配置文件里把 `widgets_color_mode` 改成 `"manual"`，`widgets_manual_color` 填颜色（比如 `"#5b7bd5"`），再重启。

**全屏游戏 / 全屏视频时**，组件暂停更新（时钟、进度条、系统状态都不读不画）。

布局保存在 `%APPDATA%\com.stanley.desktopisland\widgets-layout.json`。

## 怎么打开程序

双击运行：

```
D:\Projects\desktop-island\src-tauri\target\release\desktop-island.exe
```

只会运行一个。重复打开时，新开的会自己退出。打开全屏游戏或全屏视频时，灵动岛和架子都会自动隐藏，游戏里推鼠标到边缘也不会弹出架子。

## 音游

双击底部的律动（音频可视化）组件，选歌和难度，按空格开始，用 **A S K L** 打。

- 加歌：把 BeatSaver 下载的 zip 解压到 `charts/` 里，一首歌一个文件夹（里面要有 `Info.dat`）。不用重启。
- 谱里带着歌（`song.egg`）时游戏自己放，音乐组件和灵动岛会显示这首歌和谱里的封面。
- **← →** 调延迟（音符早了 / 晚了，每次 20ms），**↑ ↓** 调下落速度（每次 0.1 倍）。每首歌分别记住。
- Esc 随时退出，退出后一切恢复原样。

## 多套布局

编辑模式（`Ctrl+Alt+W`）顶部的「布局 1 2 3」：每套各自记住组件、位置和主题。
第一次点一个空的布局，会先复制一份现在的，再按你的喜好挪。不在编辑模式时，也能从托盘 →「桌面布局」切换。

## 屏幕边缘律动

托盘 →「**屏幕边缘律动**」：放歌时屏幕四条边跟着音乐发光（低音推上下、中音推左右），颜色跟壁纸。
鼠标永远点得穿过去；没声音、全屏游戏时自动藏起来。

## 手机遥控

托盘 →「**手机遥控**」打开后，电脑会在家里的 Wi-Fi 里开一个小网页；托盘 →「**手机遥控二维码…**」用手机扫码打开（不用装 App）。

- 看电脑正在放的歌（封面、歌名、进度），上一首 / 暂停 / 下一首
- 番茄钟：开始、暂停、继续、结束
- 看 CPU、显卡温度、电量；一键让电脑回到桌面
- 手机上打的字直接放进电脑剪贴板（电脑上 Ctrl+V）
- 手机里的照片、文件传进架子的「手机」分类（重名自动改名，不覆盖；单个最大 1GB）
- **触控板**：手机当笔记本触控板用 —— 单指移动、轻点＝左键、双指轻点＝右键、双指上下＝滚轮、点两下按住＝拖动；
  下面还有左 / 中 / 右键和鼠标侧键「返回」「前进」，灵敏度和滚动方向可调
- **窗口**：列出电脑上开着的窗口，点一下切过去；或者「上一个窗口」（Alt+Tab）
- **音游（手机模式）**：点「在电脑上打开选歌」，电脑回到桌面并弹出选歌菜单（手机上也有歌单，哪边选都行）。
  电脑照常放歌、画裂缝；手机上画着同样的靶子，直接用手指点，不用瞄准（金色一组用几根手指一起点）。
  手机会先和电脑对表，按手指碰到屏幕的那一刻判定，网络慢一点不影响；手机模式的最高分单独记。
  点得总是偏晚就调「点击补偿」。横过来拿手机格子更大，「全屏」按钮可以全屏横屏

鼠标是用系统的模拟输入做的（不碰别的程序）。以管理员身份运行的程序（比如任务管理器）系统不让模拟输入；
玩有反作弊的游戏时别用手机控鼠标，免得被当成外挂。

安全：默认关着；二维码里带一串随机密钥，没有密钥的请求一律拒绝；只接受家里局域网的连接。
第一次打开时 Windows 防火墙会问要不要允许，选「专用网络」。想让旧二维码失效：删掉配置里的 `phone_token` 再重启。

## 托盘菜单

任务栏右下角的托盘里有一个胶囊图标（如果没看到，点一下 `^` 展开隐藏图标）。左键或右键点它：

- **打开/关闭架子**
- **从桌面搬进架子…** / **把桌面来的东西搬回桌面…** / **隐藏桌面图标**
- **编辑桌面小组件**：进入 / 退出编辑模式
- **切换小组件主题** / **小组件主题预览**
- **回到桌面**：再点一次恢复
- **双击灵动岛**：选双击灵动岛时做什么——回到桌面 / 全部最小化 / 不做什么（马上生效，会记到配置里）
- **打开配置文件**：用记事本打开配置。
- **重启（应用新配置）**：改完配置后点这个才会生效。
- **开机自动启动**：打勾就会在开机后自动运行，再点一次取消。
- **退出灵动岛**

## 配置文件

位置：`%APPDATA%\com.stanley.desktopisland\config.json`（`C:\Users\User\AppData\Roaming\com.stanley.desktopisland\config.json`）。

第一次运行会自动生成，以后加了新设置会自动补上。改完保存，再从托盘点"重启（应用新配置）"。

**灵动岛**

| 键 | 默认值 | 说明 |
|---|---|---|
| `offset_x` | `0` | 水平偏移（像素，正数往右） |
| `offset_y` | `0` | 离屏幕顶部的距离（像素） |
| `color_background` | `"rgba(14, 14, 18, 0.86)"` | 底色，最后一个数是透明度（架子也用它） |
| `color_text` | `"#f2f2f5"` | 文字颜色 |
| `color_glow` | `"rgba(140, 170, 255, 0.16)"` | 平时的淡淡外发光 |
| `color_battery` | `"#ffb340"` | 低电量提醒色 |
| `color_gpu` | `"#ff5a4f"` | 显卡高温提醒色 |
| `color_done` | `"#5ee08a"` | 番茄钟完成色 |
| `hide_in_fullscreen` | `true` | 有全屏程序时自动隐藏 |
| `pomodoro_minutes` | `25` | 番茄钟分钟数 |
| `battery_low_percent` | `20` | 电量低于多少（%）且没插电时提醒 |
| `gpu_temp_limit_c` | `85` | 显卡温度达到多少（°C）时提醒；降低 3°C 后解除 |
| `gpu_poll_seconds` | `5` | 多少秒读一次显卡温度 |
| `gpu_poll_on_battery` | `false` | 用电池时也读显卡温度（双显卡笔记本可能因此唤醒独显、多耗电） |

**侧边架子**

| 键 | 默认值 | 说明 |
|---|---|---|
| `shelf_enabled` | `true` | 要不要架子 |
| `shelf_dir` | `"C:\\Users\\User\\OneDrive\\架子"` | 存放东西的文件夹（JSON 里 `\` 要写成 `\\`） |
| `shelf_zone_top` | `0.25` | 右边缘触发区域的上端（0 = 屏幕顶，1 = 底） |
| `shelf_zone_bottom` | `0.75` | 右边缘触发区域的下端 |
| `shelf_dwell_ms` | `300` | 鼠标在边缘停多久才滑出（毫秒） |
| `shelf_leave_delay_ms` | `500` | 鼠标离开后多久收回（毫秒） |
| `shelf_hotkey` | `"Ctrl+Alt+D"` | 打开 / 关闭架子的快捷键；留空 `""` 表示不用快捷键 |
| `shelf_width` | `320` | 架子宽度（像素） |

**桌面小组件**

| 键 | 默认值 | 说明 |
|---|---|---|
| `widgets_enabled` | `true` | 要不要桌面小组件 |
| `widgets_edit_hotkey` | `"Ctrl+Alt+W"` | 进入 / 退出编辑模式的快捷键；留空 `""` 表示不用快捷键 |
| `widgets_color_mode` | `"auto"` | `"auto"` 跟着壁纸变色；`"manual"` 用下面的颜色 |
| `widgets_manual_color` | `"#5b7bd5"` | 手动颜色（只在 `"manual"` 时用），浅色会自动配深色字 |
| `widgets_wallpaper_check_seconds` | `30` | Wallpaper Engine 开着时，每隔多少秒向它确认一次当前壁纸（10 ~ 3600） |
| `widgets_status_seconds` | `3` | "系统状态"组件多少秒更新一次（1 ~ 60） |
| `island_double_click` | `"desktop"` | 双击灵动岛做什么：`"desktop"` 回到桌面、`"minimize"` 全部最小化、`"off"` 不做什么（托盘里也能改） |
| `phone_enabled` | `false` | 手机遥控（托盘里也能开关） |
| `phone_port` | `8787` | 手机遥控网页用的端口 |
| `phone_token` | 自动生成 | 二维码里的密钥；删掉再重启会换一个新的，旧链接全部失效 |
| `edge_glow` | `false` | 屏幕边缘律动（托盘里也能开关） |
| `show_desktop_hotkey` | `""` | 回到桌面的快捷键，比如 `"Ctrl+Alt+Q"`；做的事和双击灵动岛一样。留空表示不用，不能用 Win+D |

颜色可以用任何 CSS 写法（`#ff8800`、`rgb(255,136,0)`、`orange`）。写错的值会被忽略，用回默认值。
文件格式写坏时（比如少了逗号），程序会用全部默认值启动，不会改你的文件。

## 常见问题

- **放歌了却没显示音乐**：这个播放器没有接入 Windows 媒体控制。可以按键盘上的音量键看看：系统弹出的音量框里没有这首歌，灵动岛也读不到。
- **"下一首"是灰的**：播放器告诉系统它不支持切歌，比如单个 YouTube 视频不在播放列表里时。
- **没有显卡高温提醒**：没装 NVIDIA 驱动（找不到 `nvidia-smi`）时会安静跳过；用电池时默认也不读。
- **在全屏游戏里还看得到**：个别游戏的全屏方式比较特殊。可以把这个游戏的名字告诉开发者，补上检测。
- **快捷键没反应**：可能被别的程序占用了，在配置里换一个（比如 `"Ctrl+Alt+Space"`）。
- **小组件不见了**：被程序窗口盖住了，按 Win+D 看看；编辑模式会把它们暂时提到最上面。
- **组件颜色没跟着壁纸变**：Wallpaper Engine 的播放列表自动换图时，最多要等 `widgets_wallpaper_check_seconds` 秒才会发现。
- **WeChat、Riot 等的快捷方式又出现在桌面上**：有些程序更新时会重新放一个快捷方式到桌面，再搬一次即可。

## 安全说明

- 不注入、不修改任何其他进程，不读取游戏内存，不会触发反作弊。
- 不监听、不记录键盘。快捷键用系统的 RegisterHotKey，只在按下那一个组合时收到通知。鼠标只读取坐标和"现在是不是在拖东西"。
- 显卡温度用 NVIDIA 官方的 `nvidia-smi` 读取。
- 隐藏桌面图标用的是资源管理器自己的"显示桌面图标"命令，只有你在托盘里点了才会执行。
- 回到桌面 / 全部最小化用的是 Windows 外壳自己的接口（Shell.Application 的 ToggleDesktop、MinimizeAll / UndoMinimizeALL），和任务栏右下角"显示桌面"是同一套，不模拟按键。
- 音频可视化用的是 Windows 自带的"环回录音"：只读取系统正在播放的声音的副本做频谱分析，不是麦克风，不保存、不上传；只有这个组件在桌面上、而且没在全屏时才会读。
- 桌面小组件只改自己的窗口（把它的"属主"设成桌面、压到最底），不改桌面或 Wallpaper Engine 的任何窗口。取壁纸用的是 Wallpaper Engine 官方命令行 `-control getWallpaper`，在看不见的控制台里运行。点组件时只读鼠标左键是否按着（为了松手后把焦点还给原来的程序），不读键盘。

## 开发

```bash
npm install
npm run tauri dev     # 开发模式，显示动画帧率
npm run tauri build   # 编译发布版（生成上面的 exe）
cd src-tauri && cargo test   # 文件安全的自动测试
cd src-tauri && cargo run --example print_osu   # 打印 charts/ 里 osu! 谱的难度、靶子数、前 20 个靶子
```

需要：Node.js、Rust（MSVC 工具链）、Visual Studio Build Tools（C++ 桌面开发：MSVC + Windows 11 SDK）。

开发模式下的测试开关：

- `ISLAND_FAKE_BATTERY=15`：模拟 15% 电量，测试低电量提醒。
- `ISLAND_TEST_DESKTOP="假桌面文件夹|假公共桌面文件夹"`：搬家功能改用这两个文件夹当桌面，不碰真桌面。
